# flask mongo assignment 

github link - http://github.com/shubham-007-yad/flask.git


This is a simple Flask project where I used Flask, JSON and MongoDB Atlas

The project has one Flask application with the following routes:

'/' - show the form
'/api/ - reads data from data.json and return it as json 
'/sumbit' - receive data and store it in mongo 
'/success' - show the success page after sumbmission 

project structure -

-app.py

-requirement

    -index.html
